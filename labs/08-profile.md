# Lab 8: Building your Public Profile
*November 12, 2026*

Code hosting services offer landing pages that are displayed when someone clicks on your username. These automatically show your contribution activity, but you can also customize them. To be honest, I've been lazy about doing this myself, but do sometimes look at peoples' profiles, particularly when new contributors appear. Beyond the open source world, recruiters and potential employers may also check out your profile if you link to it from a résumé or LinkedIn.

Throughout this activity I'm going to assume you're primarily using GitHub, but the same concepts apply to GitLab/CodeBerg/SourceHut etc.

> I recognize not everyone wants to create a public profile, so feel free to skip this lab as one of your two freebies.

## Activity Description
This week, let's take some time to:
- Be selective about which projects are featured
- Add a profile photo, location, and your real name
- Write a short README file describing your interests

## Steps
1. Visit your GitHub profile at https://github.com/your-username and log in. Open the same page in a private browser window to see what it looks like for a random viewer. Keep this one open as you work on your profile and refresh it periodically to make sure it's displaying as you like.

2. Several of your repos will show up by default. Click on "Customize your pins" at the top right of the profile page and choose specific projects to highlight. An open source project you've contributed to is probably better to show off than something from this class, for example. Pin the upstream repo, not your fork.

3. Edit your basic bio information on the left hand side. It's useful to include your location and time zone so that people know when to expect you to be online. I also recommend using your real name and photo as part of the whole "open source is built on trust" thing, but you don't have to if you want to stay anonymous.

	Feel free to add links to LinkedIn or other socials, but again, don't feel obligated.

4. Create your profile README file. This is a bit non-obvious, but you can display arbitrary text at the top of your profile page doing the following:
   1. Create a new repository named exactly the same as your username
   2. Make sure the repo is set to "public"
   3. Create a `README.md` file in the root of that new repo
   4. Populate it with content
	  
  More detailed instructions can be found in [GitHub's docs](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme)
  
4. Edit your README however you like! You can do a short and simple description of who you are and/or what your (programming-related) interests are, or you can go crazy with animated SVGs. Check out this [curated list](https://github.com/abhisheknaiidu/awesome-github-profile-readme) of profile READMEs for inspiration.
