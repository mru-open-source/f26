# Common Documents in FOSS Projects

> [!NOTE]
> All of the files listed below are usually found at the top level of a project.
> They're also typically a `md` file, but can sometimes be a `txt` file.

| File                                              | Description                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <h4>`README`</h4>                                 | Usually rendered in the front page of the project's repository. Typically contains:<br>- Overview/summary of the project<br>- Instructions on how to install it<br>- Features included<br>- The tech stack used within the project<br>- A section on contributing (and possibly a link to a `CONTRIBUTING` file) |
| <h4>`CONTRIBUTING`</h4>                           | Provides instructions on how new contributors can get started with contributing to the project.                                                                                                                                                                                                                  |
| <h4>`LICENSE` (or `COPYING`)</h4>                 | Contains the licensing information for the project.                                                                                                                                                                                                                                                              |
| <h4>`CHANGELOG`</h4>                              | Lists the different versions of the project that have been released over time, along with the changes made in each version (e.g., added features, bug fixes).                                                                                                                                                    |
| <h4>`INSTALL`</h4>                                | Lists instructions on how a new user/developer can install the project on their machine.                                                                                                                                                                                                                         |
| <h4>`CODE_OF_CONDUCT`</h4>                        | Mentions the standards and responsibilities that both contributors and maintainers both pledge to uphold within the project's community.                                                                                                                                                                         |
| <h4>`CODING_GUIDELINES` (or `CODING_STYLES`)</h4> | Explains the coding styles that developers should use in the project. This file exists to ensure future code is consistent with the existing codebase.                                                                                                                                                           |
| <h4>`AGENTS`</h4>                                 | Contains instructions, policies, and/or guidelines for AI agents.                                                                                                                                                                                                                                                |
| <h4>`CLAUDE`</h4>                                 | Contains instructions, policies, and/or guidelines specifically for [Claude Code](https://claude.com/product/claude-code).<br>- Could simply be instructions to redirect Claude Code to the `AGENTS` file.<br>- Could possibly also be code guidelines as well.                                                  |
| <h4>`SECURITY`</h4>                               | Provides instructions on how to report security vulnerabilities found within the project.                                                                                                                                                                                                                        |
| <h4>`AUTHORS`</h4>                                | Lists all the contributors and maintainers of the project.                                                                                                                                                                                                                                                       |
| <h4>`DONORS`</h4>                                 | Lists all entities (e.g., company, individual) that have donated to the project.                                                                                                                                                                                                                                 |
| <h4>`AI_POLICY`</h4>                              | Explains the guidelines and policies regarding the usage of AI within the project.<br>- Could instead be a part of the README file.                                                                                                                                                                              |
| <h4>`LOCALIZATION`</h4>                           | Guidelines for translators.                                                                                                                                                                                                                                                                                      |
