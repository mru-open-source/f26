# Evaluating Project Activity

## Seeing a project's history is an important part in determining whether it is worth contributing to!

### Things to keep in mind: 
1. GitHub Issues or GitLab Work Items serve as action items or "to dos"
    1. *"To dos" could also be described as tickets*
2. Pull or merge requests handle finishing these task items 
    1. *Pull requests are what accomplishes those to dos!*

### What to look out for:
***Charlotte likes sorting by comments sometimes to see what back and forth there is in the community***

    <br> 
    <li>
    <i> <strong>"good first issue"</strong> is a great tag to look out for when looking for projects to contribute to because it means it is beginner friendly! </i> 
    </li>
    </ul>
    </td>
  </tr>
    <th> <strong> Commits and PR </strong> </th>
    <td> 
    <ul>
        <li>Watch out for repositories that have too much PR and commits happening in a short period of time. It is good for commits to be active but any repositories having a multitude of commits within a day/week are red flags</li>
        <li><i> Look for there to be one commit every few days or so. This means the project is active but also carefully looking at the PR being sent! </i></li> 
        <li>Also look out for open requests that linger for long periods of time. It could be a yellow flag!</li>
    </td>
  </tr>
</table>

## Class Acitvity! 
### Look at some OSS. How active are the projects? What communication channels are most used?
#### Example: Godot
**What is the oldest open issue/PR**
- [w switch is not in effect when opening projects from the project manager 3070](https://github.com/godotengine/godot/issues/3070)
    - Submitted December 13, 2015
    - Last comment said “Should be closed now since the duplicate issue was fixed” on July 25 , 2025. Moderators could have forgotten to close it!
- *Other examples in class:*
    - Windows 11 Debloat - Oct 2023 → updated/changed in 2026

**What issue/PR has the most comments?**
- [TRACKER Unit tests to add or improve 43440](https://github.com/godotengine/godot/issues/43440)
    - Posted on November 10, 2020
    - Has 267 comments and has the good first issue tag
    - The reason it is still open is because it is still being actively updated. People can choose to add/improve unit tests to which people have been doing even as recent as one day ago (from the date this is written).
- *Other examples in class*
    - SpotDL - one issue with problem *(lots of me too problems)*

**What are the communication channels**
- [Godot has a website just for all their forms of communication channels](https://godotengine.org/community/)
    - Forums, Discord, Reddit, and a contributors chat are all communication forms they have
    - They also have social media such as Bluesky, Youtube, and Twitch
- *Other examples in class*
    - IRC 
    - Slack
    - Mailing Lists
- All these communication forms could be categorized as synchornous *(live responses, good for general questions)* vs asynchronous *(could take time for a response/well thought out responses)*
